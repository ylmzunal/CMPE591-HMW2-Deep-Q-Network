# Training Results

![training_results](https://github.com/user-attachments/assets/5b538bb8-9dbb-4307-b9a3-d9eff38da931)

## **Total Reward vs. Episode**
- At the start, rewards are low (~0-10).  
- Over time, rewards increase and stay around **30-40** on average.  
- Some episodes get very high rewards (above 50), but rewards still go up and down a lot.  
- This means the agent **is learning but not completely stable yet**.  

## **Reward per Step (RPS) vs. Episode**
- At first, the agent earns very little per step (~0.1-0.2).  
- Later, it **learns to get more reward per step (~0.5-0.7 on average)**.  
- Some spikes show the agent is **sometimes very efficient**, but there is still some randomness.  

## **Final Thoughts**
✅ The agent is **learning and improving**.  
✅ It gets **higher rewards as episodes increase**.  
⚠ **There is still some instability** (big ups and downs).  
🔹 **Training longer and making the model more stable** can improve results. 🚀
